# Break Time Billiards - public pages

Hosts the Break Time Billiards app's public web pages via GitHub Pages:

- `privacy.html` - privacy policy
- `support.html` - support page
- `logo.png` - logo used by those pages

The app's content (specials, events, announcements, table status) now lives in Firebase.
Owners manage it at https://break-time-billiards.web.app and bartenders update tables at
https://break-time-billiards.web.app/tables. The old GitHub-token admin pages and JSON
feeds that used to be here were removed on 2026-10-19 (they're still in this repo's history).
