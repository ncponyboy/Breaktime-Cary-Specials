# breaktime-cary-specials

Weekly specials data + admin form for the Break Time Billiards iOS app (Cary location).

- `index.html` — GitHub Pages admin form. Paste in a GitHub personal access token (repo scope) to add/remove specials; writes directly to `specials.json` via the GitHub Contents API.
- `specials.json` — the data the app fetches at runtime (raw.githubusercontent.com).

Same pattern as `ncponyboy/high-country-events-specials`.
